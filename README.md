# my-skills

내가 AI에게 매번 반복해서 시키던 일을 Claude Code 스킬로 만들어 모아 둔 저장소입니다.

## todo-summary

오늘 완료한 할 일을 요약하고, 원하면 커밋 메시지 형식으로 정리해 주는 스킬입니다.

### 왜 만들었나 (불편 → 해결)

| 불편 | 해결 |
| --- | --- |
| 하루 일을 마칠 때마다 AI에게 "Todo 앱에서 오늘 완료한 걸 `todo.js summary`로 뽑아서 커밋 메시지 형식으로 정리해 줘"라고 같은 설명을 반복했습니다. | 절차를 스킬에 적어 두어 "오늘 한 일 정리해 줘" 한마디로 끝납니다. |
| AI가 가끔 명령 대신 DB를 직접 뒤지려 하거나 `.env` 값을 보여 주려 했습니다. | "명령 결과만 사용, 로그인 정보는 출력 금지"를 스킬에 못 박았습니다. |
| 형식이 매번 조금씩 달랐습니다. | `[카테고리] 한 일` 한 줄 형식과 0건일 때 동작을 고정했습니다. |

### 구조

```
.claude/skills/todo-summary/SKILL.md   # 이름·설명(언제 쓰는지)·절차
```

### 설치

스킬을 쓸 프로젝트(`todo.js`가 있는 Todo 앱)에 폴더째 복사합니다. 이 저장소에 올리는 것만으로는 적용되지 않습니다.

```bash
cp -r .claude/skills/todo-summary <프로젝트>/.claude/skills/
```

복사 후 그 프로젝트를 연 상태에서 새 대화를 시작합니다. 프로젝트 루트에 `.env`(`TODO_EMAIL`, `TODO_PASSWORD` 등)가 있어야 하며, 이 저장소에는 인증 정보가 들어 있지 않습니다.

### 호출 문장

- "오늘 한 일 정리해 줘"
- "오늘 완료한 거 커밋 메시지로 만들어 줘"
- 직접 호출: `/todo-summary`

### 확인한 결과

todo-app 프로젝트에 설치한 뒤 **새 대화**를 열고 스킬 이름 없이 한마디만 입력했습니다. (2026-11-02)

입력:

```text
오늘 한 일 정리해 줘
```

결과: `Skill 실행됨`, 명령 1개 실행(`todo.js summary`) 후 아래처럼 답했습니다.

```text
오늘(2026-11-02) 완료한 일은 2건입니다.
- CLI 테스트 할 일 (#일반)
- 스킬 시험용 할 일 (#일반)

커밋 메시지 형식으로 정리해 드릴 수도 있습니다.
```

스킬이 한마디로 발동했고, `.env` 값은 노출되지 않았습니다.
