# 오늘 완료 요약

Todo 앱(`todo.js` CLI가 있는 프로젝트)에서 오늘 완료한 할 일을 모아 보여 준다.

## 절차

1. 프로젝트 루트에서 `node --env-file-if-exists=.env todo.js summary`를 실행한다.
2. 출력(`오늘(YYYY-MM-DD) 완료 N건`과 `- 제목 (#카테고리)` 목록)을 그대로 보여 준다.
3. 커밋 메시지 형식을 요청받았다면 카테고리별로 묶어 한 줄씩 만든다.
   - 형식: `[카테고리] 한 일`
   - 완료 건이 0건이면 메시지를 만들지 않고 "오늘 완료한 일이 없습니다"라고 알린다.

## 지킬 것

- 로그인 정보(`TODO_EMAIL`, `TODO_PASSWORD`)는 `.env`에서 읽히므로 값을 출력하거나 묻지 않는다.
- DB를 직접 뒤지지 않고 위 명령의 결과만 사용한다.
- 커밋은 만들어 주기만 하고, 사용자가 시키기 전에는 `git commit`을 실행하지 않는다.
